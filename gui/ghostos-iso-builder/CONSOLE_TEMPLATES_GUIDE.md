## How to Use Templates

### Loading a Template

1. **Open UI Designer Tab**
   - Launch the OS Builder GUI
   - Navigate to the "UI Designer" tab

2. **Browse Console Templates**
   - Scroll in the left sidebar to "Console-Style Templates" section
   - View 6 template options with previews

3. **Select Template**
   - Click on any template preview card
   - Or click the "Load Template" button
   - Confirm when prompted (this replaces current canvas)

4. **Template Loads Instantly**
   - All elements appear on the design canvas
   - Elements are fully editable
   - Properties panel shows element details

### Customizing Templates

All template elements are **100% editable**:

#### Text Customization
- Click any element
- Edit text in Properties Panel
- Change font size, color, family

#### Color Customization
- Select element(s)
- Use color pickers for:
  - Background color
  - Text color
  - Border color
- Apply consistent color schemes

#### Layout Customization
- Drag elements to new positions
- Resize with corner/edge handles
- Use alignment tools (Left, Center, Right, etc.)
- Distribute elements evenly

#### Adding Elements
- Drag widgets from Widget Library
- Match style of template
- Maintain consistent spacing

#### Removing Elements
- Select element(s)
- Press `Delete` key
- Or right-click → Remove

### Saving Custom Templates

After customization:

1. **Export Layout**
   - File → Export Layout
   - Saves JSON configuration

2. **Save as New Template**
   - File → Save as Template
   - Name your custom template
   - Add description and tags

3. **Share Templates**
   - Export to file
   - Share with team/community
   - Import others' templates

## Best Practices

### Design Consistency

1. **Color Harmony**
   - Stick to template's color scheme
   - Use 1 primary, 1 secondary, 1-2 accents
   - Maintain contrast for readability

2. **Typography**
   - Use consistent font sizes
   - Hierarchy: Headings (24-36pt), Body (14-16pt), Labels (10-12pt)
   - Limit to 2-3 font families

3. **Spacing**
   - Use grid snap (10px recommended)
   - Consistent margins: 20-30px
   - Button padding: 10-15px

4. **Interactive Elements**
   - Buttons: Clear hover states
   - Large touch targets (min 44x44px)
   - Visual feedback on selection

### Performance Tips

1. **Optimize Assets**
   - Use compressed images
   - Lazy load game tiles
   - Implement virtualization for lists

2. **Smooth Animations**
   - 60 FPS target
   - Hardware acceleration
   - Transition duration: 200-300ms

3. **Controller Support**
   - Test with gamepad
   - Implement D-pad navigation
   - Add visual focus indicators

### Accessibility

1. **Color Contrast**
   - WCAG AA minimum (4.5:1 for text)
   - Test with color blindness simulators

2. **Text Size**
   - Minimum 14pt for body text
   - Scalable text (no fixed sizes)

3. **Navigation**
   - Keyboard/controller navigable
   - Skip links for sections
   - Screen reader compatible

## Troubleshooting

### Template Won't Load
- **Issue:** Permission denied or file not found
- **Solution:** Ensure OS Builder has read/write permissions

### Elements Overlap
- **Issue:** Elements not aligned properly
- **Solution:** Use alignment tools (Left, Center, etc.) or grid snap

### Colors Look Different
- **Issue:** Monitor color calibration
- **Solution:** Use Full Preview mode, test on target display

### Performance Issues
- **Issue:** Lag when editing templates
- **Solution:** Reduce element count, optimize images, close other apps
